# หน้าเว็บสหกิจศึกษา วศ.เกษตร: วิธีอัปเดตข้อมูลและนำขึ้นเว็บไซต์

หน้าเว็บนี้ (`index.html`) อ่านข้อมูลจาก Google Sheet 2 ไฟล์ทุกครั้งที่มีคนเปิด
แก้ข้อมูลใน Google Sheet แล้วหน้าเว็บจะเปลี่ยนตามเอง ไม่ต้องแก้โค้ดหรืออัปโหลดใหม่

## 1. ไฟล์ข้อมูล (อยู่ในโฟลเดอร์ 05_งานภาค & ธุรการ)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| [สหกิจ วศ.เกษตร – บริษัท (ข้อมูลเว็บ)](https://docs.google.com/spreadsheets/d/1vztZXSnIqhemN-SXJY5x_OoSYLZGFXX4uIIBYZNDE6c/edit) | 1 แถว = 1 บริษัท: ลักษณะงาน จังหวัด โทรศัพท์ เว็บไซต์ ที่อยู่ และสาขาทักษะ (ใส่ 1) |
| [สหกิจ วศ.เกษตร – นักศึกษารายปี (ข้อมูลเว็บ)](https://docs.google.com/spreadsheets/d/1hbE3KwZZZgTQeidcBlBju83J6YAVIsqfauFUIER38ho/edit) | 1 แถว = 1 บริษัทใน 1 ปีการศึกษา: ปี หลักสูตร ชื่อบริษัท จำนวนนักศึกษา |

### เพิ่มข้อมูลปีการศึกษาใหม่
1. เปิดไฟล์ **นักศึกษารายปี** เพิ่มแถว: `ปีการศึกษา` (เช่น 2570), `หลักสูตร`, `บริษัท/หน่วยงาน`, `จำนวนนักศึกษา`
2. ชื่อบริษัทต้อง **สะกดตรงกับไฟล์บริษัททุกตัวอักษร** (แนะนำให้คัดลอกมาวาง)
3. `จังหวัดที่ไปจริง` ใส่เฉพาะกรณีนักศึกษาไปสาขาที่ต่างจากจังหวัดในไฟล์บริษัท ถ้าเว้นว่างจะใช้จังหวัดของบริษัท
4. ถ้าเป็นบริษัทใหม่ ให้เพิ่มแถวในไฟล์ **บริษัท** ก่อน แล้วใส่ `1` ในคอลัมน์สาขาทักษะที่เกี่ยวข้อง
5. ปีใหม่จะขึ้นเป็นปุ่มบนหน้าเว็บเอง ยอดรวมทุกตัวคำนวณให้อัตโนมัติ

### กติกาสำคัญ
- ห้ามเปลี่ยนชื่อหัวคอลัมน์แถวแรก และให้ข้อมูลอยู่ในแท็บแรกของไฟล์
- ชื่อจังหวัดใช้ชื่อเต็ม เช่น `กรุงเทพมหานคร`, `พระนครศรีอยุธยา` / ต่างประเทศ: เว้นจังหวัดว่าง ใส่ชื่อประเทศในคอลัมน์ `ประเทศ`
- ถ้าสะกดชื่อบริษัทหรือจังหวัดไม่ตรง หน้าเว็บจะขึ้นกล่องสีส้ม "สำหรับผู้ดูแลข้อมูล" บอกว่าแถวไหนต้องแก้
- **ไฟล์ทั้งสองจะเปิดให้ทุกคนดูได้** ห้ามใส่ชื่อ เบอร์ หรืออีเมลส่วนตัวของนักศึกษาหรือผู้ติดต่อ (ชื่อผู้ติดต่อ HR และอีเมลให้เก็บใน Excel ของภาควิชา)

## 2. เปิดให้หน้าเว็บอ่านไฟล์ได้ (ทำครั้งเดียว)

ทำกับ **ทั้งสองไฟล์**: กด **แชร์ (Share)** → ส่วน "การเข้าถึงทั่วไป" เลือก **ทุกคนที่มีลิงก์ (Anyone with the link)** → สิทธิ์ **ผู้มีสิทธิ์อ่าน (Viewer)** → เสร็จสิ้น

ถ้าบัญชี @kmitl.ac.th ไม่มีตัวเลือก "ทุกคนที่มีลิงก์" (องค์กรปิดไว้) ใช้วิธีใดวิธีหนึ่ง:
- **เผยแพร่ไปยังเว็บ:** ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ → เลือกแท็บแรก + รูปแบบ **CSV** → เผยแพร่ แล้วคัดลอกลิงก์ไปใส่ใน `index.html` ที่ `companiesCsv` / `placementsCsv`
- หรือย้ายสองไฟล์ไปไว้ใน Google Drive ส่วนตัว (Gmail) แล้วแชร์จากที่นั่น และแก้ `companiesSheetId` / `placementsSheetId` เป็นรหัสไฟล์ใหม่

ถ้ายังไม่ได้แชร์ หน้าเว็บจะยังแสดงผลได้ด้วย "ข้อมูลสำรอง" ที่ฝังไว้ (ณ 28 ต.ค. 2569) และขึ้นจุดสีส้มที่บรรทัดสถานะ เมื่อแชร์แล้วจะเป็นจุดสีเขียว "ข้อมูลล่าสุดจาก Google Sheet"

## 3. นำขึ้นเว็บไซต์ GitHub Pages

**แบบ A: ใส่เป็นหน้าหนึ่งในเว็บที่มีอยู่แล้ว**
1. เปิด repository ของเว็บบน github.com → **Add file → Upload files**
2. ลากโฟลเดอร์ `coop` (มี `index.html`) ลงไป → **Commit changes**
3. รอ 1–2 นาที แล้วเปิด `https://papabird112.github.io/<ชื่อ-repo>/coop/`

**แบบ B: แยกเป็น repository ใหม่**
1. สร้าง repository ใหม่ชื่อ `coop` (Public) → อัปโหลด `index.html` ไว้ที่ราก
2. Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save
3. เว็บจะอยู่ที่ `https://papabird112.github.io/coop/`

**ฝังในหน้าอื่นของเว็บ (ไม่บังคับ)** ใส่โค้ดนี้ในหน้าที่ต้องการ:

```html
<iframe src="https://papabird112.github.io/coop/" title="สหกิจศึกษา วศ.เกษตร"
        style="width:100%;height:1600px;border:0" loading="lazy"></iframe>
```

หรือทำเป็นปุ่มลิงก์ `<a href="https://papabird112.github.io/coop/">ดูบริษัทสหกิจศึกษา</a>` ซึ่งดูบนมือถือได้ดีกว่า
